## 🛠️ **TECHNOLOGICAL SINGULARITY (STACK)**

### 🎨 **Frontend (The Visor)**
The interface is a portal into the machine's mind, visualized with **React 18** and **WebGL**.
- **Framework**: React 18.2.0 + Vite
- **UI Kit**: Material-UI (Customized Dark Mode)
- **Data Viz**: D3.js, Recharts, Framer Motion
- **State**: Redux Toolkit + RTK Query

### 🦀 **Backend (The Engine)**
Built on **Rust** for near-metal performance and **Node.js** for rapid orchestration.
- **Trading Engine**: Rust (Tokio Async Runtime)
- **API Server**: Express.js (Optimized)
- **Communication**: gRPC (Protobuf), WebSockets (Socket.IO)
- **Data**: In-Memory Hyper-Cache, Redis

- **Time**: 5 Minutes

### ⚡ **Quick Start**

1.  **Clone the Repository**
    ```bash
    git clone https://github.com/MrDecryptDecipher/Diia.git
    cd Diia
    ```

2.  **Ignite the Engine**
    ```bash
    chmod +x start-omni.sh
    ./start-omni.sh
    ```
    *This script auto-detects your environment, installs dependencies, builds the Rust core, and launches the PM2 cluster.*

3.  **Access the Dashboard**
    - Local: `http://localhost:10001`
